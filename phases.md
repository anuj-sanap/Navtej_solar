# Navtej Solar Tech Energy — Development Phases

## Phase 0 — Discovery and Audit
Deliverables:
- Inspect existing website/project.
- Inventory reusable modules.
- Identify calculator formulas, graph behavior and pincode dependencies.
- Finalize page list and scope.
- Confirm business content/assets.

Exit criteria:
- Approved feature inventory and implementation plan.

## Phase 1 — Foundation
Deliverables:
- Repository cleanup only where needed.
- Environment configuration.
- Database connection.
- Base layout, routing and reusable components.
- Design tokens and responsive foundation.

Exit criteria:
- Application runs reliably with documented setup.

## Phase 2 — Public Website
Deliverables:
- Home.
- About.
- Services.
- Projects/gallery.
- Contact.
- Navigation/footer.
- Core CTAs.

Exit criteria:
- All public routes are responsive and linked correctly.

## Phase 3 — Solar Calculator
Deliverables:
- Input workflow.
- Validation.
- Modular calculation engine.
- Result cards.
- Graphs/charts.
- Pincode/location functionality if required by the approved logic.

Exit criteria:
- Approved test cases produce expected results and chart data.

## Phase 4 — Lead Capture
Deliverables:
- Enquiry forms.
- Database persistence.
- Validation.
- Submission states.
- Source/calculator context capture where useful.

Exit criteria:
- Valid enquiries are reliably stored and retrievable.

## Phase 5 — Admin Dashboard
Deliverables:
- Authentication.
- Enquiry management.
- Project management.
- Image/media handling.
- Authorization checks.

Exit criteria:
- Unauthorized users cannot access protected operations.

## Phase 6 — Quality and Optimization
Deliverables:
- Responsive testing.
- Form/API tests.
- Calculator test cases.
- Accessibility review.
- Performance optimization.
- SEO metadata.

Exit criteria:
- Critical user journeys pass without known blocking defects.

## Phase 7 — Deployment and Handover
Deliverables:
- Production environment configuration.
- Deployment.
- Domain/configuration handoff as applicable.
- Admin usage notes.
- Backup/maintenance notes.

Exit criteria:
- Production smoke test passes and the approved system is accessible.
